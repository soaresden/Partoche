Partoche

태블릿 속 악보에 선생님과 함께 메모해요.
간단하고, 무료이고, 계정도 필요 없어요.

🚀 학생: 8단계로 시작하기 (프랑스어)
🎻학생이에요앱을 설치하고, 악보를 정리해서 선생님과 공유해요. 🧑‍🏫선생님이에요웹 페이지를 열고, 학생을 추가해서 학생의 악보에 메모해요.
🎻 학생의 태블릿⇄☁️ 학생의 pCloud 폴더⇄🧑‍🏫 선생님 페이지

학생 5단계로 끝

안드로이드 태블릿과 pCloud 계정(무료)이 필요해요. 앱이 단계별로 안내해 줘요. (앱은 프랑스어로 되어 있어서, 괄호 안에 번역을 적어 두었어요.)

  1. 앱 설치하기

    ⬇️ 직접 다운로드 링크 (Partoche.apk)로 Partoche를 내려받아 태블릿에서 파일을 열어요(안드로이드가 물어보면 '출처를 알 수 없는 앱'을 허용해 주세요). 처음 실행할 때 Élève(학생)를 선택해요.

  2. Partoche 폴더 고르기

    앱이 세 가지 방법을 보여 줘요. 🆕 Nouvelle installation(새로 설치: 태블릿에 폴더를 만들어요), 📂 J'ai déjà un dossier Partoche(이미 Partoche 폴더가 있어요: 폴더를 찾아서 안에 뭐가 있는지 확인해요), 또는 ☁️ Directement dans mon pCloud(내 pCloud에 바로 — 추천: pCloud 사이트로 로그인, Google·2단계 인증 가능). 앱이 그 안에 모든 걸 준비해 줘요.

    Partoche/ ├── MSCZ/ 🎼 내 악보 ├── MesNotes/ ✍️ 악보별 내 메모 ├── Settings/ ⚙️ 설정, 일정, 연습 시간 └── Prof/ 📬 선생님이 보내 주는 것
    ☁️ 태블릿에 폴더를 두나요? 그렇다면 pCloud와 동기화되어 있어야 해요(예: AutoSync 앱 사용). 그렇지 않으면 선생님에게 아무것도 안 보여요. 양방향으로 동기화해 두세요.
    🔑 pCloud에 바로 연결하나요? 동기화할 필요가 없어요. pCloud 이메일과 비밀번호로 로그인하면 돼요. Google, Apple, Facebook 계정으로 가입했나요? 먼저 pCloud 계정에 비밀번호를 추가하세요(my.pcloud.com → 설정 → 계정 → 비밀번호). 그다음 이메일로 로그인하면 돼요. 2단계 인증도 돼요. 앱이 코드를 물어봐요.

  3. 내 악보함 채우기

    어떤 곡을 넣을지는 직접 정해요. .mscz 파일을 MSCZ 폴더에 복사하면 앱에 나타나요(⟳ Actualiser(새로고침) 버튼).

    💻 컴퓨터에서: pCloud로 끌어다 놓기📱 태블릿에서: pCloud 앱 → 업로드🗂️ 하위 폴더도 괜찮아요🎁 선생님이 보내 줄 수도 있어요(태그 Nouveau(새 악보))
    🎼 .mscz 파일은 어디서 구하나요? ＋ Autres partitions(악보 더 받기)를 누르면 앱이 LibreScore(무료, PC·Mac·안드로이드용)를 알려 줘요. 곡을 검색해서 .mscz로 내려받을 수 있어요. MuseScore에서 저장할 수도 있어요(파일 → 다른 이름으로 저장). 사용하는 악보의 저작권은 꼭 지켜 주세요.

  4. 선생님과 공유하기

    pcloud.com에서 Partoche 폴더는 공유 → 공유 링크를 비밀번호와 함께 만들고, Prof 폴더는 점 세 개 → 파일 요청을 만들어요(선생님이 계정 없이 파일을 넣을 수 있는 업로드 함이에요).

    그다음 앱에서 Options → Partager avec mon prof(옵션 → 선생님과 공유)를 열고 두 링크를 붙여 넣어요. 앱이 링크를 확인하고 보낼 메시지(WhatsApp, 이메일 등)를 준비해 줘요. pCloud에 바로 연결했다면 링크도 앱이 대신 만들어 줘요.

    메시지에는 초대 링크가 들어 있어요. 선생님이 링크를 누르면 아무것도 옮겨 적지 않아도 선생님 목록에 내가 나타나요.

    Options → Mon emoji et ma couleur(옵션 → 내 이모지와 색깔)에서 선생님에게 어떻게 보일지 골라요.

    💡 선생님은 아무것도 망가뜨릴 수 없어요. 악보를 읽기만 하고, 파일은 Prof 폴더에만 넣어요. 선생님은 pCloud 계정이 없어도 돼요. 새 메모나 악보가 오면 매번 알려 줘요(● Nouveau(새 악보) + 알림).
    ⏱️ 앱은 악보마다 연습한 시간도 기록해요. 선생님이 출석 화면에서 보고 일주일 동안의 연습을 확인할 수 있어요.

  5. 내 수업

    📅 Mes cours(내 수업): 다가오는 수업과 대기 중인 요청을 볼 수 있어요. 📅 Voir ses disponibilités(선생님 가능 시간 보기)를 누르면 선생님의 한 주가 보여요. 수업 가능 시간, 쉬는 날, Occupé(바쁨) 시간대가 표시돼요(다른 학생은 절대 보이지 않아요). 비어 있는 시간대를 누르면 수업을 제안할 수 있어요. 한 번만 또는 매주로요.

    두 사람이 모두 수락해야 수업이 확정돼요. 시간을 옮기려면 다른 시간을 제안하면 돼요. 요청을 보낼 때마다 앱이 메시지(WhatsApp, SMS, 이메일)로 📨 prévenir ton prof(선생님에게 알리기)를 제안해 줘요.

    📝 수업이 끝나면 선생님이 연습할 내용을 적어 줘요. 태블릿에 창이 열리고, 해당 악보는 À faire(할 일)로 바뀌어요.

선생님 6단계로 끝

컴퓨터, iPad, 태블릿 중 하나면 충분해요. 설치할 것도 없고 계정도 필요 없어요. 페이지를 열 때마다 답을 기다리는 것(수업 요청, 질문)이 먼저 보여요.

  1. 페이지 열기

    🎼 Partoche 열기

    iPad에서는 Safari에서 공유 → 홈 화면에 추가를 누르고, 앞으로는 항상 그 아이콘으로 Partoche를 열어 주세요(그래야 설정이 잘 유지돼요).

    Partoche 로고를 누르면 설정이 열려요. 언어(FR / EN / 한국어)와 브라우저 알림을 바꿀 수 있어요. 머리글은 선생님 이모지의 색깔로 바뀌어요.

  2. 이름, 이모지, 색깔 정하기

    내 학생 화면 맨 위에서 정해요. 학생 화면에서 선생님 메모 옆 작은 말풍선에 표시돼요.

  3. 학생 추가하기

    학생이 보낸 초대 링크를 누르면 학생이 자동으로 추가돼요. 아니면 내 학생 → 코드 붙여넣기를 이용하세요(P1.로 시작하는 텍스트예요). 학생마다 직접 고른 이모지와 색깔로 된 카드가 있어요. 카드를 누르면 그 학생의 악보를 볼 수 있어요. 백업 코드 복사를 눌러 메모장에 꼭 보관해 두세요. 모든 학생 정보가 들어 있어요.

  4. 메모하기!

    곡을 열면 학생의 메모에는 학생 이름이 적힌 말풍선이 붙어 있어요. 펜으로 바꾸고 써 보세요. 획 하나하나가 바로 학생에게 전송되고, Partoche가 잘 도착했는지 확인해 줘요(초록색 체크와 함께 “… 님에게 저장됨”). 학생은 실시간으로 볼 수 있어요.

    학생의 태그도 볼 수 있어요(새 악보 = 보냈지만 아직 안 연 악보, 할 일, 연습 중, 완성). 학생에게 줄 악보가 있나요? ＋ 악보 → 학생에게 악보 보내기를 누르고 컴퓨터나 iPad에서 .mscz 파일을 고르면 학생의 악보함에 들어가요.

  5. 일주일 연습 확인하기

    위쪽의 📊 출석 버튼을 누르면 지금 누가 온라인인지, 그리고 학생마다 최근 7일 동안 악보를 연습한 시간이 보여요. 학생을 누르면 마지막 접속 시간, 연습할 곡(새 악보, 할 일, 연습 중)과 곡별 연습 시간, 날짜별 자세한 기록을 볼 수 있어요.

  6. 수업 일정 잡기

    📅 내 일정에서 학생에게 수업 시간을 제안하거나 학생의 제안을 수락해요. 두 사람이 모두 수락해야 수업이 확정돼요. 시간을 옮기려면 누구든 다른 시간을 제안하면 돼요. 목록 오른쪽에는 다가오는 수업이 보여요. 수업 중에는 “수업 중” 배너가 뜨고, 수업이 끝나면 연습할 내용(메모 + 악보)을 적어 주세요. 학생 화면에 표시되고, 해당 악보는 할 일로 바뀌어요.

    반복: 매주 또는 2주마다, 수업 횟수나 종료 날짜를 정해서 반복할 수 있어요(예: “11월 5일까지 매주 목요일 10:00”). 학생은 한 번에 모두 수락할 수 있어요.

    ⚙️ 내 가능 시간: 수업 가능 시간(기본값 08:00 – 20:00: 1시간짜리 마지막 수업은 19:00에 시작해요), 쉬는 날(예: 토요일과 일요일), 안 되는 시간(시간대 하나 또는 하루 종일, 나만 보는 메모와 함께)을 정해요. 학생에게는 “바쁨”으로만 보이고, 다른 학생의 이름이나 선생님 메모는 보이지 않아요.

📘학생 안내 (선생님)선생님 페이지 맨 위: 새 학생을 위한 사용 안내를 한 번에 보내요 (WhatsApp, 이메일…).

🏷️내 태그할 일, 연습 중, 완성… 그리고 나만의 라벨: 🔥 L’enfer(지옥), 😎 Easy, 🤭 Marrant(재미), 💪 Déjà bossé(연습함)… 원하는 색으로(Options → Mes tags).
💬선생님 의견 묻기악보를 길게 누르고 « Demander l’avis de mon prof »(선생님께 묻기): 선생님은 웹 페이지의 💬 요청 버튼에서 답해요.
🎹🎵 악기 바꾸기트랙 → 소리: 파트마다 원하는 악기로, 피아노는 오른손·왼손을 따로 바꿀 수 있어요.
🤏두 손가락모든 보기 방식에서, 펜 모드에서도 확대하고 스크롤할 수 있어요. 마우스로는 클릭한 채로 끌면 돼요.

❓ 자주 묻는 질문

상대방의 메모가 안 보여요

메모는 화면에 보이는 트랙과 음 이름 설정에 연결되어 있어요. 상대방 이름이 적힌 버튼을 누르면 Partoche가 그 사람의 보기 설정으로 바꿀지 물어봐요.

내 데이터는 어디에 저장되나요?

태블릿과 pCloud에만 있어요. Partoche 서버도, 계정도, 광고도 없어요. 작은 “온라인” 신호만 공개 중계 서버(ntfy.sh)를 거쳐요. 개인정보 보호(프랑스어).

선생님: 컴퓨터나 브라우저를 바꾸면요?

학생 목록은 지금 쓰는 브라우저에 저장돼요. 새 브라우저에서 내 학생 → 코드 붙여넣기를 열고 백업 코드를 붙여 넣으세요(또는 파일 복원).

PDF 악보는요?

Partoche는 MuseScore 파일(.mscz)을 읽어요. PDF는 악보 인식 프로그램(무료인 Audiveris나 MuseScore의 PDF 가져오기)으로 변환할 수 있지만, 결과를 손봐야 하는 경우가 많아요. 가장 쉬운 방법은 LibreScore에서 곡을 찾는 거예요.
